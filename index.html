🏨 Comment utiliser la carte Hébergement

  1. 📍 Vérifiez que la ville est renseignée en haut de la page (champ Ville / Région) — la carte se centre dessus automatiquement.
  2. 🏷️ Choisissez le type d'hébergement dans la liste déroulante ci-dessous (Hôtel, Gîte, Camping…) pour filtrer les résultats sur la carte.
  3. 🖱️ Cliquez sur la carte (ordinateur) ou touchez (mobile) pour afficher les hébergements 🟡 à proximité.
  4. ✅ Cliquez sur un marqueur jaune puis sur "✓ Sélectionner" pour remplir automatiquement tous les champs.
  5. 🔍 Vous pouvez aussi taper directement le nom dans la barre de recherche ci-dessus.

💡 Carte disponible une fois la ville renseignée — double-cliquez sur la carte pour afficher les marqueurs 🟡.
